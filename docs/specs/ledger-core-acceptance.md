These are caller declarations, not authentic external evidence or accounting eligibility.

2. Retry the original with new valid transaction/entry IDs and reordered accounts/entries under the same key. Expect the first receipt, no attempted IDs, and byte-identical complete five-table history.
3. Attempts by the restricted application role to UPDATE/DELETE the original refuse with42501. Exact original history remains unchanged.
4. Append09 full inverse with new IDs, swapped sides, unchanged1250 amounts/accounts/currency/evidence and explicit original link. Expect a full reversal receipt, one09 link and08 key; both normal balances become0. Complete original readback remains posted and unchanged. Original-only cutoffs use both inclusive clocks and each clock independently.
5. Retry09 using a fresh connection and new IDs/reordering. Expect the first offset receipt, no attempted rows, unchanged original/offset/global history and the same read-only balances.
